
# Mall Customer Analysis

## 📌 Project Overview

Mall Customer Analysis is a Python-based data analysis project that explores customer demographics, annual income, spending scores, and purchasing behavior. The project uses **NumPy, Pandas, and Matplotlib** to clean, analyze, and visualize the dataset.

The main goal of this project is to understand customer behavior and identify useful patterns that can support customer segmentation and targeted marketing decisions.

## 🛠️ Technologies Used

* **Python**
* **NumPy** – Numerical operations and data processing
* **Pandas** – Data cleaning, manipulation, and analysis
* **Matplotlib** – Data visualization

## 📊 Analysis Performed

* Explored customer demographics and spending behavior.
* Analyzed **annual income and spending scores**.
* Checked and handled missing values and duplicate records.
* Examined data for unusual or outlier values.
* Studied relationships between customer attributes.
* Identified different customer behavior and spending patterns.

## 📈 Visualizations

The project includes visualizations such as:

* Bar charts
* Histograms
* Scatter plots
* Distribution plots

These visualizations help understand customer income, spending patterns, and relationships between different variables.

## 💡 Key Insights

The analysis helps identify:

* High- and low-spending customers.
* Income distribution among customers.
* Relationships between income and spending behavior.
* Customer groups with similar purchasing patterns.
* Potential opportunities for targeted marketing.

## 🚀 How to Run

1. Clone this repository.
2. Open the Jupyter Notebook.
3. Make sure the required Python libraries are installed.
4. Run the notebook cells to perform the analysis and view the visualizations.

Install the required libraries using:

```bash
pip install numpy pandas matplotlib
```
